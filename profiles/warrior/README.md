# Warrior Profile (격수PC)

이 폴더는 격수PC 실행 기준 정리용입니다.

## 실행 파일
- `svc_warrior.py` (프로젝트 루트)

## 시작 순서
1. OBS 가상카메라 ON
2. 게임 창 활성화
3. `python svc_warrior.py`
4. GUI에서 NAV/순찰 확인
5. `F2`로 자동사냥 시작

## 참고
- 격수 자동사냥 로직은 `bis_logic.py`
- F2 제어모드는 `gui_app.py`
- 순찰 포인트 CSV는 `patrol_points_cheonan_heunggga5.csv`
